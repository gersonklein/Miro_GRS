🚀 Guia Rápido, Atalhos & Publicação Online

⌨️ Atalhos Estilo Miro & PureRef

  • Espaço + Arrastar ou Botão do Meio: Mover Canvas (Pan)
  • Scroll (Roda do Mouse): Zoom na posição do cursor
  • Tab: Modo Foco PureRef (Ocultar/Mostrar Menus)
  • Duplo Clique na Imagem ou F: Zoom rápido no item / Voltar
  • Ctrl + V: Colar Imagem da área de transferência ou Texto
  • Ctrl + P: Auto-Pack (Empacotar imagens selecionadas)
  • C: Recortar Imagem selecionada (Crop não-destrutivo)
  • G: Alternar Escala de Cinza (Grayscale) na imagem
  • Alt + H / Alt + V: Espelhar Imagem Horizontal / Vertical
  • I: Conta-Gotas (Capturar cor de qualquer pixel do canvas)
  • N Post-it • T Texto • S Forma • L Conectar • P Desenhar
  • Ctrl + D: Duplicar • Ctrl + Z / Y: Desfazer / Refazer • Del: Excluir

📁 Grupos / Pastas (Project)

  • Ctrl + G: Agrupar seleção em nova pasta (frame + tag + pasta no disco)
  • Ctrl + Shift + G: Desagrupar / tirar itens do grupo
  • Ctrl + Alt + N: Nova pasta dentro da selecionada
  • Ctrl + S: Salvar Project nas pastas do computador
  • Arraste itens para dentro de um frame, ou sobre uma pasta do painel
  • Painel: F2 renomear • ←/→ recolher/expandir • Alt + clique na seta abre/fecha tudo

📝 Blocos de Texto (Blockly → .txt)

  • B + clique: novo card de blocos • soltar um .txt no canvas também cria
  • Clique no texto para editar • dois cliques na borda do bloco divide entre as linhas
  • Ctrl + Enter (editando): divide no cursor • Alt + 1..4 grifa, Alt + 0 tira
  • Paleta acima do editor ou botão direito ➔ Cor do bloco
  • Arraste um bloco para fora do card: vira card novo, ou encaixa em outro card
  • Cada card vira um .txt na pasta do grupo (blocos = parágrafos; marcadores do blocky valem)

🌐 Como Publicar Online Grátis

Este projeto é 100% Web Estático e já inclui configurações para hospedagem imediata:

  1. Opção 1 — Netlify Drop (Mais Rápido, 10 segundos):
    Acesse app.netlify.com/drop e arraste a pasta Miro_GRS inteira para a página. Você receberá um link público HTTPS na hora!
  2. Opção 2 — Vercel / GitHub Pages:
    Suba esta pasta para um repositório no GitHub e ative o GitHub Pages nas configurações, ou execute npx vercel no terminal dentro da pasta.
  3. Compartilhando Quadros com Outras Pessoas:
    Use o botão Salvar / Exportar ➔ Exportar Projeto (.mirogrs) para gerar um arquivo único contendo todas as imagens, sons, ondas sonoras e conexões.
